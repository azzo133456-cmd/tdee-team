# 賽道角色小圖（自助註冊）

競賽跑道上奔跑的角色。預設是 🏁 旗子；你可以畫自己的小圖，透過扭蛋抽到後在「🏇 賽道角色」選用。

## 怎麼新增（3 步驟，免改程式）

1. **放圖**：把小圖放到 `public/racers/<key>.png`
   - 建議方形、背景透明，賽道上會縮到約 18~20px，所以線條別太細
   - 例如要做一隻叫 `rocket` 的，就放 `public/racers/rocket.png`

2. **註冊**：編輯 `public/racers/custom_racers.json`，加一行：
   ```json
   {
     "rocket": { "label": "火箭" }
   }
   ```
   - `key` 要和檔名一致（`rocket` ↔ `rocket.png`）
   - `label` 是顯示名稱
   - `_` 開頭的 key 會被忽略（拿來寫註解用）

3. **重新部署**：推上 git，Railway 重啟後自動生效。

> 進階（清晰度）：賽道只有約 20px，原圖太大即時縮放會糊。專案有 `tools/make_racer_thumbs.py`，會把每張圖高品質縮小+銳化成 `<key>_sm.png`，賽道優先用它（沒有 _sm 時自動退回原圖）。**圖更新後請重跑這支腳本**：`python tools/make_racer_thumbs.py`。

## 自動會發生的事

- 該小圖會加入**扭蛋池**（有註冊任何賽道小圖時，扭蛋為 飾品25% / 賽道小圖15% / 寵物60%；都沒註冊時維持 飾品40% / 寵物60%，不影響寵物機率）
- 抽到 → 解鎖；重複抽到 → 退 🦴20
- 解鎖後在競賽頁「🏇 賽道角色」可選用，套用後競賽跑道上跑的就是你的小圖（**所有人都看得到**）

## 注意

- 只放**你自己畫的原創圖**，不要用有版權的角色。
